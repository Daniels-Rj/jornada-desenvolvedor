## 💻 O que é Informática?

**Informática** é a área do conhecimento responsável pelo **processamento, armazenamento, organização e transmissão de informações utilizando sistemas computacionais**.

A palavra informática está relacionada à união de:

> **Informação + Automática = Informática**

Ela envolve diversos elementos, como:

- Computadores
- Sistemas operacionais
- Programas e aplicativos
- Redes
- Internet
- Hardware
- Software
- Dados e informações

### 📌 Em resumo

> **Informática é o conjunto de conhecimentos e tecnologias utilizados para trabalhar com informações de forma automatizada por meio de sistemas computacionais.**

---

## 📊 O que é um Dado?

**Dado** é um elemento ou registro que, isoladamente, pode não possuir um significado completo.

Pode ser representado por:

- Números
- Letras
- Palavras
- Datas
- Imagens
- Sons
- Vídeos
- Símbolos

### 🧠 Exemplo

Imagine que temos:

```text
25
```

Esse valor é apenas um **dado**.

Sozinho, não sabemos se 25 representa:

- Idade
- Preço
- Quantidade
- Temperatura
- Número de produtos
- Etc.

Portanto, o dado ainda precisa de **contexto** para adquirir significado.

---

## 📋 O que é Informação?

**Informação** é o resultado da **interpretação e organização de dados**, fazendo com que eles adquiram significado e possam ser utilizados para compreensão ou tomada de decisões.

### 🧠 Exemplo

**Dado:**

```text
25
```

**Informação:**

```text
Daniel tem 25 anos.
```

Agora o número possui **contexto e significado**.

### 📌 Relação

```text
DADOS
  ↓
Processamento / Organização / Interpretação
  ↓
INFORMAÇÃO
```

### 🎯 Exemplo na prática

Imagine uma loja:

```text
Dados:
Produto: PS5
Preço: R$ 3.500
Estoque: 3 unidades
```

Quando esses dados são organizados e interpretados, podemos obter informações como:

> "A loja possui 3 PS5 disponíveis para venda pelo preço de R$ 3.500."

Essa informação pode ajudar o proprietário a tomar decisões sobre estoque, preço e vendas.

## ⚙️ Hardware

**Hardware** é a parte **física** de um sistema computacional — tudo aquilo que podemos tocar fisicamente.

### 🧩 Exemplos

- Processador (CPU)
- Memória RAM
- SSD
- HD
- Placa-mãe
- Placa de vídeo (GPU)
- Fonte de alimentação
- Monitor
- Teclado
- Mouse
- Impressora

### 📌 Exemplo simples

```text
Computador
│
├── CPU
├── RAM
├── SSD
├── Placa-mãe
├── GPU
├── Monitor
├── Teclado
└── Mouse
```

Todos esses componentes fazem parte do **hardware**.

### 🧠 Para lembrar

> **Hardware = aquilo que você consegue tocar.**

---

## 💾 Software

**Software** é o conjunto de **programas, sistemas, instruções e dados que orientam o computador sobre o que deve ser feito**.

Diferentemente do hardware, o software não é um componente físico que podemos tocar.

### 🧩 Exemplos

**Sistemas Operacionais:**

- Windows
- Linux
- macOS
- Android
- iOS

**Aplicativos e programas:**

- Navegadores
- Editores de texto
- Jogos
- Editores de imagem
- Aplicativos de comunicação

**Software de desenvolvimento:**

- IDEs
- Compiladores
- Interpretadores
- Ferramentas de desenvolvimento

### 🧠 Para lembrar

> **Software = programas e instruções que fazem o hardware executar tarefas.**

---

## 🔗 Hardware × Software

Hardware e software dependem um do outro.

Um computador possui componentes físicos, mas eles precisam de **software para receber instruções e executar tarefas**.

### 🎮 Exemplo

Quando você abre um jogo:

```text
Você
 ↓
Software (jogo)
 ↓
Sistema Operacional
 ↓
Hardware
 ↓
CPU + RAM + GPU + armazenamento
 ↓
Jogo sendo executado
```

### 📌 Resumindo

| Conceito | Significado | Exemplo |
|---|---|---|
| 💻 **Informática** | Área relacionada ao processamento e utilização automatizada de informações | Computadores e sistemas |
| 📊 **Dado** | Elemento que pode precisar de contexto para possuir significado | `25` |
| 📋 **Informação** | Dado processado e contextualizado | `25 anos` |
| ⚙️ **Hardware** | Parte física do computador | CPU, RAM, SSD |
| 💾 **Software** | Programas e instruções | Windows, navegador, jogo |

---

## 🧠 O que preciso lembrar?

> **Dado** é um elemento que pode estar sem contexto.
>
> **Informação** é o dado processado e interpretado, adquirindo significado.
>
> **Hardware** é a parte física do computador.
>
> **Software** é formado por programas e instruções.
>
> **Informática** envolve as tecnologias e conhecimentos utilizados para processar, armazenar, organizar e transmitir informações de forma automatizada.
