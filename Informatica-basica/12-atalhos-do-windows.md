# 🧠 O que são atalhos de teclado?

**Atalhos de teclado** são combinações de teclas utilizadas para executar determinadas ações de maneira mais rápida, sem precisar utilizar o mouse ou navegar pelos menus.

Eles ajudam a:

- Aumentar a produtividade;
- Economizar tempo;
- Facilitar tarefas repetitivas;
- Navegar mais rapidamente pelo sistema;
- Utilizar o computador de forma mais eficiente.

### 📌 Exemplo

Em vez de utilizar o mouse para copiar um arquivo ou texto, podemos utilizar:

```text
Ctrl + C
```

| **Backspace** | Apagar para trás |
| **Delete (Del)** | Excluir |
| **Home** | Ir para o início |
| **End** | Ir para o final |
| **Page Up** | Subir uma página |
| **Page Down** | Descer uma página |

# 🪟 Atalhos do Windows

A tecla **Windows (⊞)** pode ser combinada com outras teclas para acessar rapidamente diferentes funções do sistema.

| Atalho | Ação |
|---|---|
| `Windows` | Abrir o Menu Iniciar |

| `Windows + L` | Bloquear o computador |

| `Windows + S` | Abrir a pesquisa |
| `Windows + A` | Abrir as configurações rápidas |
| `Windows + Tab` | Abrir a Visão de Tarefas |
| `Windows + V` | Abrir o histórico da área de transferência |

# 🖥️ Atalhos para janelas

Esses atalhos ajudam a organizar e controlar as janelas abertas.

| Atalho | Ação |
|---|---|
| `Alt + Tab` | Alternar entre aplicativos abertos |
| `Alt + F4` | Fechar a janela ou aplicativo atual |
| `Windows + ↑` | Maximizar a janela |
| `Windows + ↓` | Minimizar/restaurar a janela |
| `Windows + ←` | Colocar a janela no lado esquerdo |
| `Windows + →` | Colocar a janela no lado direito |

### 📌 Exemplo

Se você estiver com:

```text
Chrome
VS Code
Explorador de Arquivos
```

pode utilizar:

```text
Alt + Tab
```

para alternar rapidamente entre eles.

# 📁 Atalhos para arquivos e pastas

| Atalho | Ação |
|---|---|
| `Ctrl + C` | Copiar |
| `Ctrl + X` | Recortar |
| `Ctrl + V` | Colar |
| `Ctrl + A` | Selecionar tudo |
| `F2` | Renomear item selecionado |
| `Delete` | Enviar item para a Lixeira |
| `Shift + Delete` | Excluir permanentemente |
| `Ctrl + Shift + N` | Criar nova pasta |
| `Alt + Enter` | Abrir propriedades do item |

### ⚠️ Atenção

O comando:

```text
Shift + Delete
```

pode excluir o item diretamente, sem enviá-lo para a Lixeira.

Por isso, deve ser utilizado com cuidado.

# ⚙️ Atalhos para o sistema

Alguns atalhos permitem acessar ferramentas importantes do Windows.

| Atalho | Ação |
|---|---|
| `Windows + R` | Abrir Executar |
| `Windows + I` | Abrir Configurações |
| `Windows + X` | Abrir menu de acesso rápido |
| `Windows + E` | Explorador de Arquivos |
| `Windows + L` | Bloquear computador |
| `Ctrl + Shift + Esc` | Abrir o Gerenciador de Tarefas |
| `Ctrl + Alt + Delete` | Abrir tela de opções de segurança |

### ⭐ Atalho importante

```text
Ctrl + Shift + Esc
```

Abre diretamente o:

```text
Gerenciador de Tarefas
```

Ele permite visualizar informações como:

- Processos em execução;
- Uso da CPU;
- Uso da memória;
- Uso do disco;
- Uso da rede;
- Aplicativos em execução.

# 📋 Área de Transferência

O Windows possui um recurso chamado **Área de Transferência (Clipboard)**.

Quando utilizamos:

```text
Ctrl + C
```

o conteúdo é copiado para a área de transferência.

Depois podemos utilizar:

```text
Ctrl + V
```

para colar.

Em versões atuais do Windows, também podemos utilizar:

```text
Windows + V
```

para visualizar o histórico da área de transferência.

## 🧠 O que preciso lembrar?

> **Atalhos de teclado** são combinações de teclas que permitem executar ações de maneira mais rápida.

> `Ctrl + C` copia e `Ctrl + V` cola.

> `Ctrl + X` recorta.

> `Ctrl + Z` desfaz uma ação.

> `Ctrl + S` salva.

> `Alt + Tab` alterna entre aplicativos.

> `Alt + F4` fecha a janela atual.

> `Windows + E` abre o Explorador de Arquivos.

> `Windows + I` abre as Configurações.

> `Windows + L` bloqueia o computador.

> `Ctrl + Shift + Esc` abre o Gerenciador de Tarefas.

> `Windows + Shift + S` permite realizar uma captura de tela.
