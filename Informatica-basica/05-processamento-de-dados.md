## 📌 O que é Processamento de Dados?

**Processamento de dados** é o conjunto de operações realizadas para **coletar, organizar, transformar e analisar dados**, produzindo informações que podem ser utilizadas para diferentes finalidades.

De forma simples:

> **Processamento de dados = transformar dados em informações úteis.**

### 🔄 Processo básico

```text
DADOS
  ↓
PROCESSAMENTO
  ↓
INFORMAÇÃO
```

### 🧠 Exemplo simples

Imagine uma loja que possui os seguintes dados:

```text
Produto: PS5
Quantidade: 3
Preço: R$ 3.500
```

Esses dados podem ser processados para descobrir o valor total do estoque:

```text
3 × R$ 3.500
       ↓
R$ 10.500
```

O resultado obtido é uma **informação** que pode ajudar na tomada de decisões.

---

# 🔄 Etapas do Processamento de Dados

O processamento de dados pode ser compreendido por meio de algumas etapas principais:

```text
ENTRADA
   ↓
PROCESSAMENTO
   ↓
SAÍDA
```

Essas etapas também podem envolver o **armazenamento** dos dados e resultados.

---

## 📥 Entrada (Input)

A **entrada** é o momento em que os dados são **coletados e inseridos no sistema**.

Os dados podem ser fornecidos por:

- Teclado;
- Mouse;
- Scanner;
- Câmeras;
- Sensores;
- Microfone;
- Sistemas e bancos de dados;
- Formulários.

### 📌 Exemplo

Em uma loja, um funcionário registra:

```text
Produto: Controle
Preço: R$ 250
Quantidade: 2
```

Esses dados representam a **entrada** do sistema.

### 🧠 Para lembrar

> **Entrada = dados que entram no sistema.**

---

## ⚙️ Processamento

O **processamento** é a etapa em que os dados são **analisados, organizados, calculados ou transformados** de acordo com determinadas regras.

O computador pode realizar operações como:

- Cálculos;
- Comparações;
- Organização;
- Classificação;
- Filtragem;
- Conversão;
- Análise.

### 📌 Exemplo

Se temos:

```text
Preço: R$ 250
Quantidade: 2
```

O sistema pode realizar:

```text
R$ 250 × 2
     ↓
R$ 500
```

### 🧠 Para lembrar

> **Processamento = transformação e manipulação dos dados.**

---

## 📤 Saída (Output)

A **saída** é o resultado obtido depois que os dados foram processados.

Ela pode ser apresentada de diferentes formas:

- Texto;
- Números;
- Gráficos;
- Imagens;
- Sons;
- Relatórios;
- Mensagens na tela.

### 📌 Exemplo

Após processar os dados da venda:

```text
Produto: Controle
Quantidade: 2
Preço unitário: R$ 250

Total: R$ 500
```

O valor total apresentado é uma **saída** do sistema.

### 🧠 Para lembrar

> **Saída = resultado produzido pelo processamento.**

---

# 💾 Armazenamento

O **armazenamento** consiste em guardar dados e informações para que possam ser utilizados posteriormente.

Os dados podem ser armazenados em:

- SSD;
- HD;
- Pen drive;
- Cartões de memória;
- Bancos de dados;
- Servidores;
- Armazenamento em nuvem.

### 📌 Exemplo

Uma loja pode armazenar:

```text
Clientes
Produtos
Vendas
Preços
Estoque
Pedidos
```

Essas informações podem ser recuperadas posteriormente quando forem necessárias.

### 🧠 Para lembrar

> **Armazenamento = guardar dados e informações para uso futuro.**

---

# 🔄 Ciclo do Processamento de Dados

Podemos representar o processo completo da seguinte maneira:

```text
             📥 ENTRADA
                 ↓
              DADOS
                 ↓
          ⚙️ PROCESSAMENTO
                 ↓
          📤 INFORMAÇÃO
                 ↓
           💾 ARMAZENAMENTO
                 ↓
        Consulta / Utilização
```

Em alguns sistemas, informações armazenadas podem voltar a ser utilizadas como entrada para novos processamentos.

```text
ENTRADA
   ↓
PROCESSAMENTO
   ↓
SAÍDA
   ↓
ARMAZENAMENTO
   ↓
NOVA ENTRADA
   ↺
```

# 💻 Processamento Manual × Automatizado

O processamento de dados pode ser realizado de diferentes maneiras.

## ✍️ Processamento Manual

É realizado principalmente por pessoas, sem depender diretamente de sistemas computacionais para executar as operações.

### 📌 Exemplo

Uma pessoa registra informações em papel e realiza cálculos manualmente.

---

## 🤖 Processamento Automatizado

É realizado utilizando sistemas computacionais capazes de executar operações automaticamente.

### 📌 Exemplo

Um sistema de vendas pode:

```text
Registrar a venda
       ↓
Calcular o valor
       ↓
Atualizar o estoque
       ↓
Registrar a operação
       ↓
Gerar o comprovante
```

Tudo isso pode acontecer automaticamente após a realização da venda.

### 🧠 Para lembrar

> **Processamento manual = depende principalmente da ação humana.**

> **Processamento automatizado = utiliza sistemas para realizar operações automaticamente.**


## 🧠 O que preciso lembrar?

> **Processamento de dados** é o conjunto de operações que transforma dados em informações úteis.

> **Entrada (Input)** é o momento em que os dados são inseridos ou coletados.

> **Processamento** é quando os dados são manipulados, organizados ou transformados.

> **Saída (Output)** é o resultado obtido após o processamento.

> **Armazenamento** permite guardar dados e informações para utilização futura.

> O processamento pode ser **manual ou automatizado**.

### 🔑 Conceito principal

```text
DADOS
  ↓
ENTRADA
  ↓
PROCESSAMENTO
  ↓
SAÍDA
  ↓
INFORMAÇÃO
  ↓
ARMAZENAMENTO
```
