## 📌 O que são Unidades de Grandeza?

As **unidades de grandeza** são utilizadas para representar e medir diferentes quantidades.

Na informática, elas são utilizadas principalmente para representar a **quantidade de dados**, a **capacidade de armazenamento** e outras grandezas relacionadas à tecnologia.

Algumas das principais unidades são:

```text
bit
byte
KB
MB
GB
TB
PB
```

---

# 🔹 Bit

O **bit** é a menor unidade de informação utilizada na computação.

A palavra **bit** vem de:

```text
Binary Digit
```

Ou seja:

```text
Dígito Binário
```

Um bit pode assumir apenas dois valores:

```text
0 ou 1
```

### 📌 Exemplo

```text
0
```

ou

```text
1
```

### 🧠 Para lembrar

> **Bit = menor unidade de informação digital = 0 ou 1.**

---

# 🔹 Byte

Um **byte** é formado por **8 bits**.

```text
1 Byte = 8 bits
```

Podemos representar:

```text
1 Byte
   ↓
8 bits
   ↓
0 1 0 1 1 0 1 0
```

O byte é uma unidade muito utilizada para representar a quantidade de dados.

### 🧠 Para lembrar

> **1 Byte = 8 bits.**

---

# 📊 Bit × Byte

É importante não confundir as duas unidades.

| Unidade | Representação | Quantidade |
|---|---|---:|
| **Bit** | `b` | 0 ou 1 |
| **Byte** | `B` | 8 bits |

### ⚠️ Atenção às letras

```text
b = bit
B = Byte
```

Essa diferença é muito importante.

---

# 📦 Múltiplos do Byte

Quando a quantidade de dados aumenta, utilizamos unidades maiores.

A sequência tradicionalmente utilizada para representar capacidades de armazenamento é:

```text
Byte
  ↓
Kilobyte (KB)
  ↓
Megabyte (MB)
  ↓
Gigabyte (GB)
  ↓
Terabyte (TB)
  ↓
Petabyte (PB)
```

---

# 🔢 Kilobyte — KB

O **Kilobyte (KB)** representa uma quantidade maior de dados do que um byte.

Na convenção decimal utilizada para capacidades de armazenamento:

```text
1 KB = 1.000 Bytes
```

### 🧠 Para lembrar

> **Kilo = mil.**

```text
1 KB = 1.000 Bytes
```

---

# 🔢 Megabyte — MB

O **Megabyte (MB)** é uma unidade maior que o Kilobyte.

```text
1 MB = 1.000 KB
```

Portanto:

```text
1 MB = 1.000.000 Bytes
```

### 🧠 Para lembrar

> **Mega = milhão.**

```text
1 MB ≈ 1 milhão de Bytes
```

---

# 🔢 Gigabyte — GB

O **Gigabyte (GB)** é uma unidade maior que o Megabyte.

```text
1 GB = 1.000 MB
```

Portanto:

```text
1 GB = 1.000.000.000 Bytes
```

### 🧠 Para lembrar

> **Giga = bilhão.**

```text
1 GB ≈ 1 bilhão de Bytes
```

---

# 🔢 Terabyte — TB

O **Terabyte (TB)** é uma unidade maior que o Gigabyte.

```text
1 TB = 1.000 GB
```

Portanto:

```text
1 TB = 1.000.000.000.000 Bytes
```

### 🧠 Para lembrar

> **Tera = trilhão.**

```text
1 TB ≈ 1 trilhão de Bytes
```

---

# 🔢 Petabyte — PB

O **Petabyte (PB)** é uma unidade ainda maior.

```text
1 PB = 1.000 TB
```

Portanto:

```text
1 PB = 1.000.000 TB
```

É uma unidade utilizada principalmente quando estamos lidando com **quantidades extremamente grandes de dados**.

### 📌 Exemplos de ambientes que podem trabalhar com grandes volumes de dados:

- Grandes empresas;
- Data centers;
- Serviços de armazenamento;
- Bancos de dados;
- Empresas de tecnologia;
- Sistemas de Big Data.

# 💻 Exemplos no dia a dia

Essas unidades aparecem constantemente quando utilizamos tecnologia.

Um SSD pode possuir:

```text
500 GB
```

```text
1 TB
```

Isso representa a capacidade aproximada de armazenamento do dispositivo.

### 📱 Celular

Um celular pode possuir:

```text
128 GB de armazenamento
```

Isso significa que ele possui uma capacidade de armazenamento de aproximadamente **128 bilhões de Bytes**, considerando a convenção decimal.

---

### 🎮 Jogos

Um jogo pode ocupar:

```text
80 GB
```

Isso representa uma grande quantidade de dados armazenados no dispositivo.

---

### 📷 Fotos e vídeos

Uma foto pode ocupar alguns:

```text
MB
```

Enquanto um vídeo pode ocupar:

```text
MB
GB
```

# 🌐 Bit também aparece em velocidades

O **bit** também é muito utilizado para representar **velocidade de transmissão de dados**.

Por exemplo:

```text
500 Mbps
```

Significa:

```text
500 Megabits por segundo
```

### ⚠️ Atenção

Em velocidades de internet, normalmente utilizamos:

```text
b = bit
```

Por isso:

```text
Mbps = Megabits por segundo
```

Já o armazenamento normalmente é representado com:

```text
B = Byte
```

Por exemplo:

```text
500 GB
```

---

# ⚠️ Bit × Byte nas velocidades

É importante diferenciar:

```text
Mb = Megabit
MB = Megabyte
```

Como:

```text
1 Byte = 8 bits
```

temos:

```text
1 MB = 8 Mb
```

### 📌 Exemplo simplificado

Uma conexão de:

```text
800 Mbps
```

possui uma taxa teórica equivalente a aproximadamente:

```text
100 MB/s
```

porque:

```text
800 ÷ 8 = 100
```

---

# 🧮 Decimal × Binário

Existe uma diferença importante entre as unidades utilizadas no **sistema decimal** e as unidades baseadas em potências de 2.

No sistema decimal:

```text
1 KB = 1.000 Bytes
1 MB = 1.000 KB
1 GB = 1.000 MB
1 TB = 1.000 GB
```

Na computação também existem unidades baseadas em potências de 2:

```text
1 KiB = 1.024 Bytes
1 MiB = 1.024 KiB
1 GiB = 1.024 MiB
1 TiB = 1.024 GiB
```

### 📌 Diferença de nomenclatura

| Decimal | Binário |
|---|---|
| KB | KiB |
| MB | MiB |
| GB | GiB |
| TB | TiB |

### 🧠 Importante

> **KB, MB, GB e TB** são unidades decimais.

> **KiB, MiB, GiB e TiB** são unidades binárias.

Essa diferença pode aparecer principalmente quando comparamos a capacidade anunciada de um dispositivo com a capacidade exibida pelo sistema operacional.

## 🧠 O que preciso lembrar?

> **Bit** é a menor unidade de informação digital e pode representar `0` ou `1`.

> **1 Byte = 8 bits.**

> **b** representa bit e **B** representa Byte.

> **KB, MB, GB, TB e PB** representam quantidades cada vez maiores de dados.

> **Mbps** significa Megabits por segundo e é utilizado para representar velocidades de transmissão de dados.

> **MB/s** significa Megabytes por segundo.

> Para converter **bits em Bytes**, podemos dividir por **8**.

```text
Bits → Bytes
÷ 8
```

> Para converter **Bytes em bits**, multiplicamos por **8**.

```text
Bytes → Bits
× 8
```

### 🔑 Escala principal

```text
1 Byte = 8 bits

1 KB = 1.000 Bytes
1 MB = 1.000 KB
1 GB = 1.000 MB
1 TB = 1.000 GB
1 PB = 1.000 TB
```
