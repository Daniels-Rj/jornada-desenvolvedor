# Principais Protocolos e Portas de Comunicação

## 1. O que é um protocolo?

Um **protocolo de comunicação** é um conjunto de regras que define como dispositivos e sistemas devem se comunicar em uma rede.

Exemplos:

- HTTP
- HTTPS
- DNS
- FTP
- SMTP
- TCP
- UDP
- SSH
- DHCP

Cada protocolo possui uma finalidade diferente.
