# ⌨️ Guia Definitivo de Atalhos do VS Code

Um resumo rápido e prático dos atalhos mais úteis para aumentar sua produtividade no dia a dia com o Visual Studio Code.

> **Dica:** No macOS, substitua `Ctrl` por `Cmd` (⌘) e `Alt` por `Option` (⌥).

---

## 🔍 Busca e Navegação

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Paleta de Comandos** | `Ctrl + Shift + P` ou `F1` | `Cmd + Shift + P` ou `F1` |
| **Ir para o Arquivo** | `Ctrl + P` | `Cmd + P` |
| **Ir para o Símbolo (Função/Classe)** | `Ctrl + Shift + O` | `Cmd + Shift + O` |
| **Ir para a Linha** | `Ctrl + G` | `Ctrl + G` |
| **Navegar para Definição** | `F12` | `F12` |
| **Ver Definição (Peek)** | `Alt + F12` | `Option + F12` |

---

## 📝 Edição e Manipulação de Código

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Copiar linha para baixo/cima** | `Shift + Alt + Down/Up` | `Shift + Option + Down/Up` |
| **Mover linha para baixo/cima** | `Alt + Down/Up` | `Option + Down/Up` |
| **Apagar linha atual** | `Ctrl + Shift + K` | `Cmd + Shift + K` |
| **Inserir linha abaixo** | `Ctrl + Enter` | `Cmd + Enter` |
| **Inserir linha acima** | `Ctrl + Shift + Enter` | `Cmd + Shift + Enter` |
| **Comentar/Descomentar linha** | `Ctrl + ;` | `Cmd + ;` |
| **Comentar bloco de código** | `Shift + Alt + A` | `Shift + Option + A` |

---

## 🎯 Múltiplos Cursores e Seleção

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Adicionar cursor (clique)** | `Alt + Clique` | `Option + Clique` |
| **Adicionar cursor abaixo/acima** | `Ctrl + Alt + Down/Up` | `Cmd + Option + Down/Up` |
| **Selecionar próxima ocorrência** | `Ctrl + D` | `Cmd + D` |
| **Selecionar todas as ocorrências** | `Ctrl + Shift + L` | `Cmd + Shift + L` |
| **Expandir seleção** | `Shift + Alt + Right` | `Shift + Option + Right` |
| **Retrair seleção** | `Shift + Alt + Left` | `Shift + Option + Left` |

---

## 📂 Gerenciamento de Janelas e Abas

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Dividir Editor (lado a lado)** | `Ctrl + \` | `Cmd + \` |
| **Focar no Editor 1, 2 ou 3** | `Ctrl + 1`, `Ctrl + 2`, `Ctrl + 3` | `Cmd + 1`, `Cmd + 2`, `Cmd + 3` |
| **Fechar aba atual** | `Ctrl + W` | `Cmd + W` |
| **Reabrir aba fechada** | `Ctrl + Shift + T` | `Cmd + Shift + T` |
| **Alternar entre abas abertas** | `Ctrl + Tab` | `Ctrl + Tab` |

---

## 🛠️ Visualização e Painéis

| Ação | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Alternar Barra Lateral (Explorer)** | `Ctrl + B` | `Cmd + B` |
| **Abrir Terminal Integrado** | `Ctrl + `` (crase)` | `Ctrl + `` (crase)` |
| **Alternar Painel (Terminal/Debug)** | `Ctrl + J` | `Cmd + J` |
| **Modo Tela Cheia** | `F11` | `Ctrl + Cmd + F` |
| **Zoom In / Zoom Out** | `Ctrl + =` / `Ctrl + -` | `Cmd + =` / `Cmd + -` |

---

## 💡 Dicas Bônus

* **Formatar Código:** `Shift + Alt + F` (Windows/Linux) ou `Shift + Option + F` (macOS).
* **Renomear Símbolo em todo o projeto:** Selecione a variável/função e aperte `F2`.
